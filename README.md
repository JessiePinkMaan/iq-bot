# NOEMA · Telegram IQ Test Bot

Премиальный Telegram-бот для прохождения авторского IQ-теста: 20 заданий, 7 категорий мышления, персональный аналитический отчёт и разблокировка результата за **50 Telegram Stars**.

Проект полностью реализован: код, база данных, вопросы, дизайн-ассеты, оплата, админ-панель, тесты и инструкция запуска.

---

## Что уже реализовано

### Пользовательский сценарий
- Красивый экран приветствия с фирменной иллюстрацией.
- 20 уникальных авторских заданий с ростом сложности.
- Один вопрос на экране, 4 варианта, прогресс `N / 20` и текстовая шкала.
- Мгновенный переход к следующему вопросу без показа правильного ответа.
- Сохранение прогресса в SQLite - тест можно продолжить после перезапуска.
- Защита от параллельных тестов и повторных ответов.
- Анимированный экран аналитики после 20-го ответа.
- Paywall: полный отчёт виден только после подтверждённой оплаты.
- Настоящая оплата Telegram Stars (`XTR`, 50 ⭐).
- Персональный отчёт: результат, точность, профиль по 7 категориям, сильные стороны, зоны роста, разбор ошибок.
- Повторное открытие оплаченного отчёта из архива.
- Кнопка «Пройти тест заново».

### Платёжная безопасность
- `pre_checkout_query` с проверкой суммы, валюты, владельца и статуса теста.
- Разблокировка **только** по `successful_payment`.
- HMAC-подпись payload: `test_id` и `user_id` нельзя подделать.
- `UNIQUE` на `telegram_payment_charge_id`.
- Идемпотентность: повторный платёж не открывает отчёт второй раз и не раздувает выручку.
- Чужие отчёты недоступны: каждый callback проверяет владельца.
- Повторная оплата фиксируется как `duplicate` и отправляется уведомление админу.

### Админ-панель
- Пользователи, новые регистрации, запущенные/завершённые тесты.
- Количество оплат, выручка в Stars, конверсия, средний результат.
- Последние пользователи и последние результаты.
- Просмотр конкретного теста.
- Рассылка с предпросмотром и подтверждением.
- Доступ только для ID из `ADMIN_IDS`.

## Быстрый запуск

### 1. Создай бота

1. Открой [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Придумай имя и username.
3. Скопируй токен вида `123456789:AAH...`.
4. Узнай свой Telegram ID у [@userinfobot](https://t.me/userinfobot).

### 2. Заполни `.env`

```env
BOT_TOKEN=123456789:AAH...
ADMIN_IDS=123456789
PRICE_STARS=50
PAYMENT_SECRET=длинная-случайная-строка
SUPPORT_CONTACT=@your_support
```

`PAYMENT_SECRET` лучше задать постоянным. Если оставить пустым, он будет выведен из токена бота - при смене токена старые неоплаченные счета станут недействительны.

### 3. Установи зависимости

**Windows (PowerShell):**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

**Linux / macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 4. Запусти

**Windows - просто дважды кликни `start.bat`.**

Или вручную:

```bash
python run.py
```

В консоли появится:

```text
NOEMA запущен. База: .../data/noema.sqlite3
```

Открой бота в Telegram и отправь `/start`.

## Telegram Stars: как это работает

Для цифровых товаров Telegram использует **Stars** (`XTR`). Внешний платёжный провайдер и `provider_token` не нужны: бот отправляет счёт через `sendInvoice` с пустым `provider_token`, валютой `XTR` и ценой `50`.

Последовательность:

1. Пользователь завершает тест.
2. Бот показывает экран с заблокированным отчётом.
3. По кнопке «Открыть результат · 50 ⭐» отправляется invoice.
4. Telegram присылает `pre_checkout_query` - бот проверяет payload, владельца, статус, сумму и валюту.
5. После оплаты приходит `successful_payment`.
6. Бот атомарно записывает платёж, ставит `paid = 1` и отправляет отчёт.
7. При повторном запуске отчёт доступен через «Мои результаты» без оплаты.

> Для теста можно временно поставить `PRICE_STARS=1`. В продакшене верни `50`.
> Stars зачисляются на баланс бота; вывод средств выполняется через инструменты Telegram для владельцев ботов.

## Авторские вопросы

20 заданий, сложность растёт от 1 до 5:

- числовые последовательности;
- поиск лишнего;
- силлогизмы и проверка условий;
- куб `3×3×3`, развёртки, сложение листа;
- визуальная матрица `3×3` (отдельная иллюстрация);
- Fibonacci, чередующиеся шаги, `n² + 1`, `×2 + n`;
- турнирная таблица, счёт цифр, семейная логика;
- задача с выключателями и лампой;
- задача о правдивом подозреваемом;
- часы, отстающие на 2 минуты в час.

У каждого вопроса есть:
- текст;
- 4 варианта;
- один правильный ответ;
- объяснение;
- уровень сложности;
- категория.

Проверка целостности запускается при старте бота и в `scripts/selftest.py`.

## Проверка проекта

```bash
python scripts/selftest.py
```

Скрипт проверяет:

- структуру 20 вопросов и покрытие 7 категорий;
- лимиты Telegram на тексты и caption;
- отсутствие утечки результата до оплаты;
- создание теста, запрет параллельного теста;
- запрет ответа не по порядку и ответа за другого пользователя;
- завершение теста и подсчёт результата;
- оплату, выручку, повторную оплату и `UNIQUE charge_id`;
- HMAC-подпись и подделку payload;
- недоступность чужого результата;
- сохранение оплаты и ответов после перезапуска;
- наличие и размеры всех изображений.

Ожидаемый финал:

```text
ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ: 83
```

Сквозной сценарий через фейковый Telegram API (без сети):

```bash
python scripts/flowtest.py
```

Проверяются приветствие, все 20 ответов, paywall без утечки результата, invoice, `pre_checkout_query`, `successful_payment`, полный отчёт, повторная оплата, чужой callback, восстановление доступа, админ-панель и рассылка. Ожидаемый финал:

```text
FLOW OK: 62 проверок
```

Симулировать настоящий `successful_payment` без Telegram нельзя - платёж проверяется только реальным платежом в Stars. Все остальные уровни покрыты selftest-ом и flowtest-ом.

Коротко:

```bash
docker compose up -d --build

```

База и логи останутся в `./data` и `./logs` на хосте.

```ini

```

sudo systemctl daemon-reload

## Что нужно добавить самостоятельно

1. **`BOT_TOKEN`** - токен из [@BotFather](https://t.me/BotFather).
2. **`ADMIN_IDS`** - твой Telegram ID (можно несколько через запятую).
3. **`PAYMENT_SECRET`** - желательно постоянную случайную строку.
4. **`SUPPORT_CONTACT`** - username поддержки, если планируешь принимать обращения.
5. **Настроить профиль бота в BotFather** (необязательно): аватар, описание, имя. Код сам устанавливает команды и описание через API.
6. **Проверить оплату в реальном Telegram** на тестовой цене `PRICE_STARS=1`, затем вернуть `50`.
7. **Юридические документы** (если нужно): условия оказания услуг и политика конфиденциальности. Бот хранит Telegram ID, username, ответы и платежи.
8. **Домен/вебхук не нужны** - используется long polling. Для больших нагрузок можно перейти на webhook и PostgreSQL, но текущая архитектура рассчитана на асинхронную работу и умеренный трафик.

## Важные детали

- Это **авторский интеллектуальный тест**, а не клиническая шкала IQ. Бот не показывает выдуманный «коэффициент» и честно указывает число верных ответов и точность.
- Нет фальшивых таймеров, скидок и накрученной статистики.
- Полный результат не отправляется до `successful_payment`.
- После оплаты отчёт можно открывать повторно.
- Повторная оплата не выдаёт отчёт второй раз: платёж фиксируется как `duplicate`, администратор получает уведомление для возврата.
- Если пользователь заблокировал бота, рассылка помечает его и больше не отправляет ему сообщения.
- Ошибки логируются в `logs/bot.log` с ротацией 5 МБ × 3.
